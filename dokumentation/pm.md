## Inledning
Målet med arbetet var att göra ett klicker-spel utifrån en mall, (Eller från scratch). Samt välja ämne och tema att göra spelet utifrån.

## Bakgrund
De olika sakerna jag gjort/ändrat på under projektet är:
- Valt tema (klegg) att göra projektet utifrån
- Ai-genererat bilder till arbetet utifrån tema med hjälp av microsoft copilot
- Ändrat/lagt till text och bilder med hjälp av css
- Ändrat/lagt till achievements och uppgraderingar i javascript-filen
- Ändrat på hur pengar (klegg) läggs till i summan så att det blir mer "smooth" med hjälp av javascript (tack Henrik)
- Hittat och lagt till ljudeffekter till klick, upgraderingar och achievements med html och css
- Ändrat hur ljudet spelas så att de kan överlappa med hjälp av javascript (tack Henrik)
- Ändrat på borders och andra visuella element för att lägga till mer "JUICE" med hjälp av css

## Vad gick bra?

Jag tycker att det gick bra att göra spelet som helhet. Det var roligt och jag lärde mig mer om javascript, html och css. Jag lyckades välja ett roligt tema som gjorde mig engegerad till att göra uppgiften. För att se till att jag är engegerad i framtiden kan jag se till att göra uppgifterna roliga på ett eller annat sätt.

## Vad gick mindre bra?

Hemsidan är inte så jätteunik eftersom den gjordes utifrån en mall. Vissa gjorde från scratch vilket jag nästan önskar att jag hade gjort för då hade det nog blivit mer lärorikt och mer unikt. I framtiden kommer vi antagligen arbeta mer med att påbörja projekt från scratch så då slipper jag känna mig sämre för att jag inte gjorde det.
